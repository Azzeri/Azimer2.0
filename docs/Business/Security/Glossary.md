# Ubiquitous Language Glossary - Security Context

## Nouns

1. **Security**: An overall term describing all authentication and authorization related stuff.
2. **Tenant**: A user who has been authenticated within the system.
3. **Password**: The secret key used by an authenticated user for verification, usually hashed.
4. **Status**: The current state of the user account, such as ACTIVE or INACTIVE.
5. **LoginHistory**: A record of a user's login attempts, including details like time, browser, and success status.
6. **LoginHistoryEntry**: An entry in the login history that logs a specific login attempt.
7. **Role**: A role that defines a set of resources for an authenticated user within the system.
8. **Resource**: A resource within the system that can be accessed or managed based on the user's roles.

## Verbs

1. **Authenticate**: The process of verifying a user's identity using their login credentials.
2. **Authorize**: The process of granting or denying permissions to an authenticated user based on their roles and resources.
3. **Logout**: The process of logging out of the system
